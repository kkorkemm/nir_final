# Редактор диаграмм классов UML с поддержкой прямого и обратного проектирования

В этом репозитории:
* `nir2` - исходный код
* `примеры numl` - файлы с расширением .numl, в которых хранятся диаграммы
* `примеры кода` - файлы с расширением .cs (C#), которые были сгенерированы редактором, а также могут быть использованы для проверки работы парсера
* `редактор.exe` - исполняемый файл
* `демонстрация работы.mp4` - видео с демонстрацией работы редактора
